# Contributing to Remote TV

Open an issue before substantial changes. Keep pull requests focused and include
the Android version, CPU ABI, reproduction steps, expected behavior and relevant
validation. Remove addresses, device identifiers, pairing codes and credentials
from logs before sharing them.

Follow the build instructions in README.md. Preserve the dependency versions and
lockfiles unless your change requires updating them. Test TV D-pad navigation,
focus visibility and background lifecycle when changing the interface.

Run the CI checks locally before submitting. Contributions are distributed under
the project's MIT license; preserve existing copyright and dependency notices.
